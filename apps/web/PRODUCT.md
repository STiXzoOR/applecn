# applecn

**What it is.** Apple's Human Interface Guidelines rebuilt as a shadcn design system: tokens generated from Apple's published and measured values, components on Base UI with Hugeicons, a shadcn registry and a documentation site. Three idioms from one stylesheet: iOS 26 (Liquid Glass), macOS 26 (Tahoe) and Apple's own web (apple.com and its web apps).

**Who it is for.** Front-end engineers and designers building products that should feel native to Apple's platforms on the web, and coding agents that install components from the registry.

**Register.** The site has two surfaces: the landing page (brand: it must look and feel like an Apple product page, because that is the promise) and the documentation (product: reference tables, live examples, install commands).

**Voice.** Precise, measured, quietly confident. Every number has a source. No marketing superlatives; the components are the evidence.

**Success.** A visitor recognises the iOS 26 switch, the macOS 26 button and apple.com's type at a glance, flips the platform switch and sees the whole page change, then copies one install command.
